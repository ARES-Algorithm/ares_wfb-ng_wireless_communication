## 目标环境验证

Ubuntu 24.04 的实际 Python 3.12 执行、ARM64、DKMS 驱动安装、模块加载、Secure Boot、
开机加载与无线服务启动需要在目标机器上验证。

开发检查环境创建 UDP socket 时返回 PermissionError，因此端到端 UDP 数据交付、负载一致性、
数据报边界、无线吞吐、功率与丢包测量属于现场验证项。

## 现场检查顺序

1. 在两端运行安装向导，选择对应角色，使用匹配密钥和无线参数。
2. 检查两端 wfb-radio.service 状态和日志。
3. 按 UDP 接口文档在两端运行应用，确认双向接收内容。
4. 检查应用计数和 WFB 统计，测量目标负载下的交付率与延迟。
5. 重启设备后检查模块加载、服务自启和双向收发。

应用地址及示例见 [UDP 接口](udp-interface.md)。
